# Easy8 Form Designer

A no-code Custom Forms Builder plugin for Easy8 (Redmine-derived) — lets
administrators design structured request forms that create correctly-fielded,
correctly-routed Easy8 tasks on submission, instead of a blank general-purpose
task form.

Personal / pet-project build. Full PRD, MoSCoW scope, and design references
live outside this repo, in the companion Claude Code project folder
(`easy8-form-designer` under `~/.claude/projects/`) — see that project's
`README.md` and `docs/prd.md`.

Tracking task: [Easy8 #687043 — Custom Forms Builder](https://es.easy8.com/issues/687043)
